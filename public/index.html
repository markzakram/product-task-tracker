build_circle Inisialisasi Spreadsheet

Jalankan sekali setelah deploy untuk memastikan sheet Main, OPTIONS, COMMENTS, ACTIVITY, header, dan dropdown sudah siap. Aman diulang — data yang sudah ada tidak dihapus.

Versi aplikasi terpasang:

group_off Kelola User & Peran

Menambah anggota tim dan mengubah peran hanya bisa dari mode Dev — termasuk untuk Manager. Ini disengaja agar penambahan akses lewat satu pintu saja.

Perlu menambah anggota baru (mis. anak magang)? Hubungi pemegang mode Dev, atau tambahkan barisnya langsung di sheet USERS pada spreadsheet.

group Kelola User & Peran MODE DEV

Tabel di bawah memuat semua nama yang dikenal sistem — termasuk yang dipakai di task tapi belum punya peran — jadi peran siapa pun bisa diubah di sini tanpa mengubah kode. User baru otomatis masuk ke dropdown PIC & Support sehingga langsung bisa diberi task.

pin Atur PIN User (Mode Dev)

Set/ubah PIN 4 digit tiap user (termasuk manager). PIN disimpan ter-hash di sheet AUTH tersembunyi. User yang punya PIN akan diminta PIN saat mode-nya dipilih.

Dropdown Master

Kelola pilihan Status, Priority, Stage, Platform, PIC, Support, Approval Gate. Perubahan diterapkan juga sebagai data validation di Spreadsheet.

account_tree Kata Kerja & Objek per Stage

Atur Kata Kerja tiap Stage, lalu Objek tiap Kata Kerja. Saat input: Stage → Kata Kerja → Objek. Nama task = Kata Kerja [Jumlah] Objek [Detail].

Daftar Stage dikelola di kartu Stage di atas. Di sini atur Kata Kerja & Objek untuk tiap Stage.

Riwayat Aktivitas

Catatan siapa membuat, mengubah, menghapus task & komentar. Tersimpan di sheet ACTIVITY.
